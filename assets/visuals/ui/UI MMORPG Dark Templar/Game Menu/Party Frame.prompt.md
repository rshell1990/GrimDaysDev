# Party Frame

Generated with the built-in image generation tool. Source art is preserved; Godot imports it at 256 pixels for reusable 24-pixel nine-slice corners.

## Prompt

Use case: stylized-concept.
Asset type: production Godot nine-slice UI border PNG, 1024x1024 square.
Primary request: create a single empty rectangular frame matching the UI MMORPG Dark Templar Game Menu style reference visible in this conversation: dark charcoal dry-brushed panels, distressed paint edges, very restrained dark rust/crimson accents.
Composition: front-facing axis aligned square frame near canvas edges, only a narrow approximately 24 pixel band of artwork on each edge, simple square corners entirely within 48 pixel corner areas; straight edge runs suitable for stretching in a nine-slice UI. Subtle worn grey inner rim readable on near-black backgrounds, almost black outer brush edge. No ornament protruding into center.
Transparency: actual transparent alpha both throughout the entire empty center and outside the frame. No solid panel fill, no checkerboard painted into image. Keep central area from x=64 through 960 and y=64 through 960 completely transparent.
No text, icons, scenery, symbols, gold, chrome, bevelled fantasy ornaments, lighting bloom or cast shadows. One frame only, not an atlas or UI mockup.
